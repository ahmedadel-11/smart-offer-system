### User Flow
1. User fills in project name (required)
2. User selects or searches for customer (required)
3. User selects currency (default: USD)
4. User specifies number of panels (1-50)
5. User sets default margin percentage
6. User optionally adds team members
7. User optionally adds notes
8. User selects initial status
9. User clicks "Create Project"
10. System creates project with specified panels
11. User is redirected to Panel Designer page

### Validation
- Project name: Required, max 200 characters
- Customer: Required
- Number of panels: Required, 1-50
- Default margin: 0-100%

### Left Panel: Material Catalog
1. **Search Bar**: Quick search across all materials
2. **Category Tabs**: Filter by material category
3. **Advanced Filters** (Collapsible):
   - Description (text search)
   - Rated Current (dropdown: 6A, 10A, 16A, 25A, 32A, 40A, 63A, 100A, etc.)
   - Isc (dropdown: 6kA, 10kA, 15kA, 25kA, 36kA, 50kA, etc.)
   - Reference (text search)
4. **Material Cards**: Clickable to add to panel

### Right Panel: Panel Items
1. **Four Drop Zones**:
   - Incoming (green header)
   - Outgoing (blue header)
   - Enclosure (orange header)
   - Busbar & Cables (purple header)
2. **Unassigned Zone**: New items land here first
3. **Drag & Drop**: Move items between zones
4. **Quantity Editor**: Inline quantity adjustment

### User Flow
1. User selects a panel tab
2. User searches/filters materials in the catalog
3. User clicks "+" to add material to panel
4. Material appears in "Unassigned" zone
5. User drags material to appropriate zone
6. User adjusts quantities as needed
7. User repeats for all materials
8. User switches to next panel
9. When done, clicks "Generate Offer"
